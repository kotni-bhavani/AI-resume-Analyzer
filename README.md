# 📄 AI Resume Analyzer

## 🚀 Overview
AI Resume Analyzer is a simple web application that analyzes resumes (PDF) and provides:
- Resume score
- Skills detected
- Missing skill suggestions

Built using Python and Streamlit.

---

## 🛠️ Technologies Used
- Python
- Streamlit
- PyPDF2

---

## 📂 Project Structure
resume-analyzer/
│── app.py
│── README.md

---

## ⚙️ Installation

1. Clone the repository:
git clone https://github.com/your-username/resume-analyzer.git

2. Navigate to project folder:
cd resume-analyzer

3. Install dependencies:
pip install streamlit PyPDF2

---

## ▶️ Run the Project

streamlit run app.py

---

## 📊 Features
- Upload resume in PDF format
- Extract text from resume
- Analyze skills
- Generate score
- Suggest missing skills

---

## ⚠️ Note
- Works only with text-based PDFs
- Scanned images may not work
