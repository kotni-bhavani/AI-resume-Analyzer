# 📄 AI Resume Analyzer

## 🚀 Overview
AI Resume Analyzer is a simple web application that analyzes resumes (PDF) and provides:
- Resume score
- Skills detected
- Missing skill suggestions

Built using Python and Streamlit.

---

## 🛠️ Technologies Used
- Python
- Streamlit
- PyPDF2

---

## 📂 Project Structure
resume-analyzer/
│── app.py
│── README.md

---

## ⚙️ Installation

1. Clone the repository:
   https://github.com/kotni-bhavani/AI-resume-Analyzer/edit/main/README.md

3. Navigate to project folder:
cd resume-analyzer

4. Install dependencies:
pip install streamlit PyPDF2

---

## ▶️ Run the Project

streamlit run app.py
https://ai-resume-analyzer-jryu79kj9uujac4xsjgck7.streamlit.app/

---

## 📊 Features
- Upload resume in PDF format
- Extract text from resume
- Analyze skills
- Generate score
- Suggest missing skills

---

## ⚠️ Note
- Works only with text-based PDFs
- Scanned images may not work
